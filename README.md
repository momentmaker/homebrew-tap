# homebrew-tap

Homebrew tap for [momentmaker](https://github.com/momentmaker) tools.

## Install

```sh
brew tap momentmaker/tap
brew install momentmaker/tap/jutsu
```

Or in one line:

```sh
brew install momentmaker/tap/jutsu
```

## Formulae

| Formula | Source | Description |
| ------- | ------ | ----------- |
| `jutsu` | [momentmaker/kaijutsu](https://github.com/momentmaker/kaijutsu) | CLI for the [kaijutsu](https://kaijutsu.dev) open-skills registry. |

Formulae are generated automatically by [goreleaser](https://goreleaser.com/) when each upstream repository cuts a `v*.*.*` release tag.
